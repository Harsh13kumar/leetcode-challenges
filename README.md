
# 🚀 LeetCode Challenges

A personal repository containing my solutions to LeetCode problems.

This repository documents my journey of learning Data Structures and Algorithms (DSA), improving problem-solving skills, and preparing for coding interviews through consistent LeetCode practice.

## 📚 About

The goal of this repository is to:

* Practice solving coding problems regularly.
* Learn common algorithmic patterns and data structures.
* Track my progress over time.
* Build a personal reference of solutions and approaches.
* Improve coding interview readiness.

## 📂 Repository Structure

Each problem is stored in its own directory using the following naming convention:

```text
<problem-number>-<problem-title>
```

Examples:

```text
0001-two-sum
0009-palindrome-number
0013-roman-to-integer
2144-minimum-cost-of-buying-candies-with-discount
3633-earliest-finish-time-for-land-and-water-rides
```

Each folder typically contains:

* Problem solution
* Complexity analysis
* Notes or observations (when applicable)
